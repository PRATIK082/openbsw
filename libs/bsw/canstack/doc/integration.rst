Integration
===========

Code-first configuration
------------------------

The whole stack is configured with C++ tables. Frame and signal layouts are
plain aggregates (``FrameTableEntry``/``SignalTableEntry``), so they can be
declared ``constexpr`` and are typically generated from a DBC file (see
:doc:`dbc_generation`).

.. code-block:: cpp

   #include "canstack/CanHwStub.h"
   #include "canstack/CanInterface.h"
   #include "canTables.h" // generated by tools/can/dbc_to_openbsw.py

   namespace
   {
   ::canstack::CanHwStub g_canHwDriver0; // use a real driver on hardware

   constexpr ::canstack::CanChannelConfig g_canChannelConfigs[]
       = {{0U, &g_canHwDriver0, 500000U, 2U}};
   } // namespace

   bool configureCanStack(::async::ContextType context)
   {
       ::canstack::CanStackConfig config{};
       config.channelConfigs = g_canChannelConfigs;
       config.channelCount    = 1U;
       config.frameTable      = g_canFrameTable;
       config.frameCount      = g_canFrameTableCount;
       config.signalTable     = g_canSignalTable;
       config.signalCount     = g_canSignalTableCount;

       ::canstack::CanSubsystem::getInstance().configure(config, context);
       return true;
   }

Lifecycle integration
---------------------

``CanSubsystem`` binds the stack to the OpenBSW lifecycle:

* ``init()`` builds the stack from the configuration.
* ``run()`` schedules the periodic main functions (tx scheduler, rx
  processing) with a 1 ms period in the configured async context; the OSAL
  maps the context to a FreeRTOS/ThreadX task.
* ``shutdown()`` cancels the periodic execution and stops all channels.

Register it with the LifecycleManager like any other component:

.. code-block:: cpp

   lifecycleManager.registerComponent(::canstack::CanSubsystem::getInstance());

On hardware, link the driver of the platform transceiver through
``CanHwTransceiverAdapter``:

.. code-block:: cpp

   #include <canstack/CanHwTransceiverAdapter.h>

   ::canstack::CanHwTransceiverAdapter g_canHwDriver0{platformCanTransceiver};

Application usage
-----------------

Application components work on signal level; cyclic transmission is handled
by the scheduler:

.. code-block:: cpp

   class EngineControl : public ::lifecycle::SimpleLifecycleComponent
   {
   protected:
       void init() override
       {
           auto& can = ::canstack::CanSubsystem::getInstance().getCanInterface();
           can.registerSignalCallback(
               "VehicleSpeed", [this](double speed) { onVehicleSpeedUpdate(speed); });
       }

       void run() override
       {
           auto& can = ::canstack::CanSubsystem::getInstance().getCanInterface();

           ::canstack::TxSignalEntry targetSpeedEntry;
           targetSpeedEntry.signalName  = "TargetSpeed";
           targetSpeedEntry.frameId     = 0x200U;
           targetSpeedEntry.channelId   = 0U;
           targetSpeedEntry.cycleTimeMs = 10U;
           can.getTxScheduler().registerSignal(targetSpeedEntry);
       }

       void mainCycle() // e.g. from the component's own periodic task
       {
           auto& can = ::canstack::CanSubsystem::getInstance().getCanInterface();
           can.sendSignal("TargetSpeed", computeTargetSpeed());
       }

   private:
       void onVehicleSpeedUpdate(double speed) { _currentSpeed = speed; }

       double _currentSpeed = 0.0;
   };

Alternative APIs:

* ``sendFrame(channelId, frameId, dlc, data)`` bypasses the database for
  custom protocols.
* ``readSignal(name)`` returns the last received value (0.0 when unknown).
* ``getRouter().addRoutingRule(...)`` configures gateway rules.
* ``CanInterface::getInstance()`` is available for components that prefer
  the singleton over the subsystem accessor.

Threading
----------

``mainFunctionTx()``/``mainFunctionRx()`` are invoked from the subsystem's
async context (dedicated task). Drivers that dispatch from interrupt context
(the transceiver adapter) push into the bounded receive queue;
``mainFunctionRx()`` drains it. The queue depth is
``canstack::CANSTACK_RX_QUEUE_DEPTH``; overflowing frames are dropped and
counted.
